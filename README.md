# PinMeTo plugins for Claude

Official Claude plugin marketplace for [PinMeTo](https://www.pinmeto.com/).

## Add this marketplace

In Claude Desktop or Claude Code, add the marketplace:

```
/plugin marketplace add PinMeTo/claude-plugins
```

Then install a plugin:

```
/plugin install pinmeto-locations@pinmeto
```

## Plugins

| Plugin | Description |
| --- | --- |
| [`pinmeto-locations`](./plugins/pinmeto-locations) | PinMeTo location data and analytics reports for Google, Facebook and Apple. Bundles the PinMeTo Location MCP server and the PinMeTo Location Reports skill. |
