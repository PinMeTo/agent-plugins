# PinMeTo plugins for Claude

Official PinMeTo plugins.

## PinMeTo Locations

Your PinMeTo location data in Claude, plus board-ready PDF and PowerPoint reports.
Bundles the [Location Reports skill](https://github.com/PinMeTo/pinmeto-location-reports-skill),
which turns data from the [PinMeTo Location MCP server](https://github.com/PinMeTo/pinmeto-location-mcp)
into reports.

### Install

1. **Install the data connection (Desktop Extension).** Download the latest `.mcpb`
   from the [pinmeto-location-mcp releases](https://github.com/PinMeTo/pinmeto-location-mcp/releases),
   then double-click it (or drag it into Claude Desktop -> **Settings** -> **Extensions**)
   and enter your three API credentials when prompted.
2. **(Optional) Reports.** Add this marketplace — **Customize** -> **Plugins** -> **+**
   -> **Add marketplace** -> enter `PinMeTo/claude-plugins` — then install
   **PinMeTo Locations** to get the report skill.

Credentials come from [PinMeTo Account Settings](https://places.pinmeto.com/account-settings/pinmeto/api/v3).

While this repository is private, installing requires the Claude GitHub App to have access to it.

### What is inside

This plugin ships the **PinMeTo Location Reports** skill, which turns location data
into monthly, quarterly, half-yearly, or yearly reports, plus a **setup** skill that
walks through configuration. The twelve read-only MCP tools it reports on — covering
locations, Google insights, reviews, ratings and keywords, Facebook insights and
ratings, and Apple Maps insights — come from the **PinMeTo Location MCP Desktop
Extension**, installed separately (see Install).

### Versioning

`plugins/pinmeto-locations/skills/pinmeto-location-reports/` is generated by
`.github/workflows/sync.yml` and must not be hand-edited. The `pinmeto-setup` skill is
hand-authored, not generated. The plugin version tracks the vendored skill version;
`components.json` records which skill version is vendored.
